Cómo se guarda tu avance

Ejercicio sin terminar: si el navegador permite guardar, puedes retomarlo aquí con la misma cuenta. No cuenta como clase completada ni se pasa a otro dispositivo.

Clase terminada: espera el aviso «Progreso guardado en tu cuenta» para saber que quedó confirmada.

Si aparece «Pendiente de guardar», pulsa «Reintentar». Si el aviso dice que no pudo conservar el avance, no cierres ni recargues antes de reintentar.
